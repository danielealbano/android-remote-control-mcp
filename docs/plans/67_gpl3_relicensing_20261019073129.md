# Plan 67 — Relicense to GPL-3.0-or-later (with Google Play services additional permission)

Move the project from MIT to the GNU GPL version 3 or later, add the GPLv3 section 7 additional permission that lets
the `gms` flavor ship with the proprietary Google Play services client libraries, publish the list of bundled
third-party components, and surface the new license in the About screen. Every outside contributor has already given
consent (collected by the owner outside this repository), so no MIT notice for the project's own license remains.

**Why GPLv3 and not GPLv2 (not derivable from code):** 315 of the 332 Maven artifacts shipped in the APK are
Apache-2.0-only; Apache-2.0 is compatible with GPLv3 but not with GPLv2. The `ring` crate linked into
`libngrok_java.so` is `Apache-2.0 AND ISC`.

**Precondition:** `main` MUST already contain the `vendor/ngrok-java` submodule bump to ngrok 0.19.0 with the `ring`
backend (PR #192). Earlier submodule commits link `ring 0.16.20` and `webpki 0.21.4`, whose OpenSSL/SSLeay-licensed
code is GPL-incompatible. Task 0.1 verifies this against `origin/main` itself (not against the working tree).

**Pre-existing compiler warnings handled by this plan:** a clean compile of `main` prints 85 Kotlin `w:` lines from 45 distinct
sites: 24 `hiltViewModel()` calls in the 18 `:app` files that import the deprecated
`androidx.hilt.navigation.compose.hiltViewModel`, 19 further `:app` sites in 14 files (12 main, 2 test: deprecated
platform/Compose APIs, redundant null handling) and 2 sites in `:e2e-tests` (deprecated `URL(String)`); a cache-less
compile of `:privacy`, `:privacy-benchmark` and `:compose-test-app` reports none. They would fail the `^w:` gates of User Story 6, so
User Story 4 removes every one of them (owner decision 2026-10-19: one plan, no separate PR).

**Decisions taken by the owner on 2026-10-18/19 (do NOT re-open):**
- License `GPL-3.0-or-later`; copyright line `Copyright 2026-2027 Daniele Salvatore Albano` (as in the current file).
- Section 7 additional permission covering ALL `com.google.android.gms` libraries, in `LICENSE.md` itself, before the
  verbatim GPLv3 text. One license file only. GitHub's repository "license" label is not a goal of this plan.
- No per-file license headers. Source files are not touched for licensing purposes.
- `CONTRIBUTING.md` states that contributing implies consent to publish under GPL-3.0-or-later. No CLA, no DCO.
- `THIRD_PARTY_LICENSES.md` is hand-maintained and version-less: one row per upstream project for Gradle
  dependencies, one row per Go module compiled into `libcloudflared.so`, one row per Rust crate compiled into
  `libngrok_java.so`. No generator, no CI freshness check.
- About screen: license item `GNU GPLv3 or later` opening `LICENSE.md` on GitHub (today's `/LICENSE` link is
  broken); new item `Third-party licenses` opening `THIRD_PARTY_LICENSES.md`; footer with copyright, license and
  no-warranty statement.
- `e2e-tests/src/test/resources/simple-calculator.apk` (GPL-3.0-only test fixture) gets a README naming its source.
- Same-project follow-ups from the PR #192 code review are part of this plan, not separate PRs (owner decision
  2026-10-19): the removal of every pre-existing Kotlin compiler warning (User Story 4), the Rust 1.85+ requirement
  in `CONTRIBUTING.md` and `Makefile` (Task 3.2), and the CI cache keys hashing `Cargo.lock` and `build.rs` (Task 3.3).

### Task 1.1 — Write `LICENSE.md`

**Action 1 — run** (repository root, Linux; on macOS use `shasum -a 256` in place of `sha256sum`). The script
aborts before touching `LICENSE.md` if the download, the checksum or the size check fails; never substitute another
copy of the GPL text and never reflow it.

```bash
set -euo pipefail
GPL="$(mktemp)"
curl -sfL https://www.gnu.org/licenses/gpl-3.0.txt -o "$GPL"
echo "3972dc9744f6499f0f9b2dbf76696f2ae7ad8af9b23dde66d6af86c9dfb36986  $GPL" | sha256sum -c
test "$(wc -c < "$GPL" | tr -d ' ')" = "35149"

Android Remote Control MCP

This program is free software: you can redistribute it and/or modify it under
the terms of the GNU General Public License as published by the Free Software
Foundation, either version 3 of the License, or (at your option) any later
version. The full text of the license follows the additional permission below.

This program is distributed in the hope that it will be useful, but WITHOUT ANY
WARRANTY; without even the implied warranty of MERCHANTABILITY or FITNESS FOR A
PARTICULAR PURPOSE. See the GNU General Public License for more details.

Additional permission under GNU GPL version 3 section 7
```
